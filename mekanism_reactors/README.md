# Mekanism Reactor Management Scripts

These scripts are designed to provide wireless control and monitoring capabilities to Mekanism reactors and related structures. This is achieved through the use of relay and monitor devices, sending and recieving wireless transmissions for commands and relaying information to a central monitor for statuses at a glance.

The system of Mekanism reactors and structures supported includes a fission reactor with a turbine, a fusion reactor, an induction matrix, and an SPS reactor is soon to come.
